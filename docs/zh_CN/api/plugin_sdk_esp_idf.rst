Plugin SDK — ESP-IDF
====================

:link_to_translation:`en:[English]`

概述
----

Host 向 L3 插件导出的 ESP-IDF 符号（错误码、日志、HTTP Client、NVS、堆查询、定时器、
证书包）。完整行为以 Host 所用 IDF 版本的官方编程指南为准；本页是
``minihub_plugin_sdk/esp_idf.h`` 中的 **白名单子集** 。

.. include-build-file:: inc/esp_idf.inc

另见：:doc:`plugin_host`。
