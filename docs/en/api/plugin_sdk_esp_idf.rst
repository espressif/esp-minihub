Plugin SDK — ESP-IDF
====================

:link_to_translation:`zh_CN:[中文]`

Overview
--------

ESP-IDF symbols Host exports to ELF plugins (error codes, logging, HTTP client,
NVS, heap query, timer, certificate bundle). Full IDF behavior is documented in
the ESP-IDF programming guide for the Host IDF version; this page is the
**allowlisted** subset from ``minihub_plugin_sdk/esp_idf.h``.

.. include-build-file:: inc/esp_idf.inc

See also: :doc:`plugin_host`.
