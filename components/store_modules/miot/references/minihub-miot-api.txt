# MiniHub Hub REST：米家云相关 API
# 完整操作流程见 docs/14-MIoT云接入Checklist.md

GET  /api/miot/status              登录状态、user_id、region
POST /api/miot/login               {"username","password"} -> ok | verify | fail
POST /api/miot/logout              清除会话与 miot.devices[]
POST /api/miot/session             导入 MiService 等导出的会话字段
POST /api/miot/login/verify/send   发送 2FA 验证码（可选 icode 图形码）
POST /api/miot/login/verify        提交 2FA ticket
POST /api/miot/login/retry         浏览器 2FA 后重试登录
GET  /api/miot/devices             云端设备列表 JSON
POST /api/miot/sync                同步到 /data/config/adapters.json miot.devices[]

# 模块 RPC（实际入口：POST /api/modules/miot/rpc ，body: {"method","params"}）
# method=status|login|session|logout|sync|devices|verify_send|verify|login_retry
# method=prop_get     params: {did, siid, piid}
# method=prop_probe   params: {did, siid_min?, siid_max?, piid_min?, piid_max?, batch?}

POST /api/command                  {"point_id":"light/miot_xxx","cmd":"turn_on"|"turn_off"|"toggle"|"set_brightness",...}
GET  /api/points                   含 adapter=miot 的能力点
POST /api/hub/reload               重载 adapters / 动态模块

POST /api/store/install            {"kind":"module","id":"miot",...}  # 动态模块模式
GET  /api/modules                  已安装模块 manifest 状态
