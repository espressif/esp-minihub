# ========== Passport 登录（account.xiaomi.com）==========
GET  https://account.xiaomi.com/pass/serviceLogin?sid=xiaomiio&_json=true
POST https://account.xiaomi.com/pass/serviceLoginAuth2
GET  https://account.xiaomi.com/identity/auth/verify...     # 2FA 浏览器验证链
POST https://account.xiaomi.com/identity/auth/send...Ticket  # 发送 2FA 验证码
POST https://account.xiaomi.com/identity/auth/verify...    # 提交 2FA ticket

# ========== 业务 API（api.io.mi.com）==========
# 基址（miot_cloud.c api_base）：
#   region=cn  -> https://api.io.mi.com/app
#   region=de|sg|us|... -> https://{region}.api.io.mi.com/app
#
# 请求：POST，表单 signature + _nonce + data（JSON 经 RC4+签名，见 miot_cloud_sign_request）
# Cookie：userId, serviceToken, PassportDeviceId（可选）
# Header：User-Agent 含 deviceId；x-xiaomi-protocal-flag-cli（见 miot_http_post_cloud）

POST {base}/home/device_list
     data 示例：{"getVirtualModel":false,"getHuamiDevices":0}
     响应 list[] 每项常见字段：did, name, model, token(32hex), mac, localip
     MiniHub sync 会写入 adapters.json 的 token/mac/ip（供 LAN miIO）；
     did 以 blt. 开头，或 model 为 camera/tv/wifispeaker/lock：不写 token/ip，mode 固定 cloud

POST {base}/v2/homeroom/gethome
     data 示例：{"limit":150,"fetch_share":true,"fetch_share_dev":true,"plat_form":0,"app_ver":9}
     响应 result.homelist[] / share_home_list[]：
       id, name, roomlist[]{id,name,dids[]}, dids[]（未分配房间）
     MiniHub：homes RPC 列家庭；sync 按 home_id 过滤并写入 name/room_*/home_*

POST {base}/miotspec/prop/get
     data 示例：{"params":[{"did":"<did>","siid":2,"piid":1}]}
     （旧接口；轮询已改走 v2）

POST {base}/v2/miotspec/prop/get
     data 示例：{"datasource":2,"params":[{"did":"<did>","siid":2,"piid":1}]}
     datasource: 1=缓存 2=设备(经网关) 3=自动
     MiniHub：adapter 轮询 / 单属性 prop_get 用 datasource=2；RPC prop_probe 批量用 1

POST {base}/miotspec/prop/set
     data 示例：{"params":[{"did":"<did>","siid":2,"piid":1,"value":true}]}

POST {base}/v2/device/blt_get_beaconkey   (ENCRYPT-RC4)
     data 示例：{"did":"blt.<...>","pdid":1}
     响应 result.beaconkey（hex，供 xiaomi_ble.bindkeys）
     MiniHub：miot sync 对 did 以 blt. 开头的设备自动拉取并写入 adapters.xiaomi_ble.bindkeys
